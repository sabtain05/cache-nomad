# Security Policy

## Supported Versions

Security updates are provided for the following versions of `cache-nomad`:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `cache-nomad` seriously. If you discover a security vulnerability within this project, please do not open a public issue. 

Instead, please send an email to the maintainer at [sabtainalipk144@gmail.com].

Please include the following information in your report:
* The type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
* Full paths of source file(s) related to the manifestation of the issue
* The location of the affected source code (tag/branch/commit or direct URL)
* Any special configuration required to reproduce the issue
* Step-by-step instructions to reproduce the issue
* Proof-of-concept or exploit code (if possible)
* The impact of the issue, including how an attacker might exploit the issue

All security vulnerabilities will be promptly investigated. We will reply to your report within 48 hours to acknowledge receipt and outline the next steps.
